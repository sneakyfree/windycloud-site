# WindyCloud.com — Marketing Website

The cloud built for AI creators. Store your intelligence.

## 🌟 Overview

WindyCloud is the central storage and compute platform of the **Windy Empire** ecosystem. This is the production marketing website built to showcase:

- **Voice model storage** — WindyClone avatars, training data, soul files
- **Transcription archives** — Every WindyWord conversation
- **Cross-app sync** — One account, every Windy app
- **Model vault** — Store 2,000+ specialized translation models
- **Cloud compute** — Overflow STT/TTS processing

## 🚀 Tech Stack

- **Vite** — Lightning-fast build tool
- **React** — UI framework
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Smooth animations and transitions

## 📦 Installation

```bash
npm install
```

## 🛠️ Development

```bash
npm run dev
```

Visit `http://localhost:5173` to see the site in development mode.

## 🏗️ Build for Production

```bash
npm run build
```

Output will be in `dist/` directory, ready for deployment to Cloudflare Pages.

## 📤 Deployment

This site is configured for **Cloudflare Pages** deployment:

1. Connect this repo to Cloudflare Pages
2. Set build command: `npm run build`
3. Set output directory: `dist`
4. Deploy!
